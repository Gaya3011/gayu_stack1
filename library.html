LIBRARY MANAGEMENT SYSTEM

Software Development Life Cycle Based Project

1. Requirement Analysis

The Library Management System helps students and librarians manage books, student details, book issue and book return.

  • Student registration
  • Book search
  • Book issue
  • Book return
  • Book availability

2. System Design

Module Purpose
Student Details Store student information
Book Search Search for available books
Book Issue Issue a book to a student
Book Return Return the borrowed book

3. Implementation

The system interface is created using HTML. Forms, tables, input boxes and selection lists are used to collect library information.

4. Testing

Test Case Expected Result
Enter Student Details Student details should be accepted
Search Book Book details should be displayed
Select Book Selected book should appear
Submit Form Form should be submitted

5. Deployment

After testing, the Library Management System can be deployed on a web server and accessed using a web browser.

6. Maintenance

The system can be improved by adding a database, student login, book availability tracking, fine calculation and admin management.
